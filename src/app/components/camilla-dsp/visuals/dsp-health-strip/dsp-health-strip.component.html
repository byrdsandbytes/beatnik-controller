Samples that exceeded 0 dBFS and were clipped. Should stay at 0; anything higher means audible distortion, so lower the master volume or the filter gain.

Processing load of the DSP. Above 80% there is little reserve left; above 95% dropouts are likely.
Buffer
Number of samples waiting in the playback buffer. A stable value is healthy; a value close to 0 means the output is running dry.
